# Қыран (ИИ Tandau): как включить

Сайт лежит на GitHub Pages, а там нельзя прятать ключи. Поэтому между сайтом и ИИ стоит маленький бесплатный сервер на Cloudflare — файл `worker.js` из этой папки. Он хранит ключ в секрете и отвечает сайту.

Порядок ответов:
1. **Google Gemini** — основной ИИ (бесплатный ключ).
2. **Cloudflare Workers AI** — запасной, если у Gemini закончился дневной лимит. Ключ не нужен.
3. **База Tandau** — если интернета нет или сервер не настроен, сайт отвечает сам (как раньше).

Время: примерно 15 минут. Деньги: 0 ₸, карта не нужна.

## 1. Ключ Gemini
1. Откройте https://aistudio.google.com и войдите через Google-аккаунт.
2. Нажмите **Get API key → Create API key**.
3. Скопируйте ключ (длинная строка). Никому его не отправляйте и не вставляйте в `index.html`.

## 2. Сервер на Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный план).
2. Слева откройте **Workers & Pages** (может называться **Compute → Workers**) → **Create** → **Create Worker** (шаблон Hello World).
3. Имя: `tandau-ai` → **Deploy**.
4. Нажмите **Edit code**, удалите весь код и вставьте содержимое `worker.js` → **Deploy**.
5. Вернитесь к воркеру → **Settings → Variables and Secrets → Add**:
   - Type: **Secret**, Name: `GEMINI_API_KEY`, Value: ваш ключ → **Deploy**.
6. **Settings → Bindings → Add → Workers AI**, Variable name: `AI` → **Deploy**.

## 3. Проверка
Откройте в браузере адрес воркера, например `https://tandau-ai.ВАШ-ПОДДОМЕН.workers.dev`.
Должно появиться:
```
{"ok":true,"service":"Tandau AI","gemini":true,"workersAI":true}
```
Если `gemini:false` — не добавлен секрет (шаг 2.5). Если `workersAI:false` — нет привязки (шаг 2.6).

## 4. Подключить к сайту
1. В репозитории откройте `index.html` → значок карандаша (Edit).
2. Найдите (Ctrl+F) строку `const AI_ENDPOINT = '';`
3. Вставьте адрес воркера: `const AI_ENDPOINT = 'https://tandau-ai.ВАШ-ПОДДОМЕН.workers.dev';`
4. **Commit changes**. Через 1–2 минуты на сайте у Қырана появится зелёная метка «Онлайн».

## Полезно знать
- Воркер принимает запросы только с `https://aidonama.github.io` (и `localhost:8123` для проверки). Если сайт переедет на свой домен, добавьте в Variables переменную `EXTRA_ORIGIN` с новым адресом.
- Модель можно поменять без правки кода: переменная `GEMINI_MODEL` (например, `gemini-2.5-flash-lite`) или `CF_MODEL` для запасного ИИ.
- Вместе с вопросом сайт отправляет имя, класс и результаты тестов, чтобы советы были личными. Школьник может это выключить галочкой «Учитывать мои тесты и предметы» в чате. На бесплатном тарифе Google может использовать запросы для улучшения своих сервисов — это стоит упомянуть в дипломе в разделе о данных.
- Лимит: не больше 12 вопросов в минуту с одного устройства, вопрос — до 1000 символов.
